Two-Compartment Drug Delivery

design an infusion controller so the drug concentration in the heart tracks a target

System · two-compartment pharmacokinetic model

dc₁/dt = −(k₀+k₁)·c₁ + k₁·c₂ + b₀·u
dc₂/dt = k₂·c₁ − k₂·c₂
y = c₂   (measured output)
In state-space form, with c = [c₁ ; c₂]:   ċ = A·c + B·u,  A = [ −(k₀+k₁), k₁ ; k₂, −k₂ ],  B = [ b₀ ; 0 ],  y = [0 1]·c.
open-loop poles: —
c₁
bloodstream concentration (compartment 1) — a state; not measured
c₂ = y
heart concentration (compartment 2) — the measured, controlled output
u
control input — drug infusion rate into the bloodstream
k₀
elimination rate from the bloodstream (= q₀/V₁)
k₁
blood→heart exchange coefficient (= q/V₁)
k₂
heart→blood exchange coefficient (= q/V₂)
b₀
input gain (= c₀/V₁, injected concentration / blood volume)

The model.  A drug is infused into the bloodstream (compartment 1) at rate u; it exchanges with the heart (compartment 2) and is eliminated from the blood. We control c₂, which we can measure; c₁ we cannot. The linear plant ċ = A c + B u is integrated with fixed-step RK4. Because the plant has no free integrator, pure proportional feedback leaves a steady-state error — add feed-forward or integral action to close it.
